Date Highlighter

Sites

One entry per line: a host pattern, optionally followed by CSS selectors that limit highlighting to matching elements. Use * to allow every site, *.example.com for a domain and its subdomains, or an exact hostname such as jira.example.com.

Examples:

*
example.com
*.atlassian.net: td[data-column-type$=":datepicker"], span.date

Date formats

Stages

Stages are day ranges relative to today. Colours apply to the "highlight" text and background.
